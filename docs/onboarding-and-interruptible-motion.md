# 引导、旧提醒清理与可中断动画

开发版本：0.19.60-next.3。

引导连续展示欢迎、协议、登录账号、后台与桌面、完成五个步骤。登录和跳过登录均前进到后台与桌面页，避免多次返回旧页面再切换到完成页。完成图案为原创空心圆与圆角对号，继续使用原有彩色流光。

后台与桌面页允许用户自行打开系统后台运行、电池优化、自启动页面，并选择添加 2×2 或 4×2 组件。小米自启动入口不可用时退回应用详情；电池设置也有系统兜底。应用不会自动授予权限，无法公开读取的自启动状态也不会标记为“已授予”。步骤允许跳过，已有用户可在设置中重新打开“后台与桌面”。系统电池优化状态根据 Android 公共接口读取，限制仍取决于系统。参考 [Android 后台电池优化说明](https://developer.android.com/training/monitoring-device-state/doze-standby)。

原实验性功能页面、旧通知模型、调度逻辑、课表更新后的旧通知提示和本地通知插件均已移除。升级清理仅读取旧插件自己的计划缓存，取消对应 PendingIntent，并删除旧“上课提醒”“测试通知”渠道；保留独立课程实时活动和桌面组件使用的闹钟、通知。配置持久化时丢弃旧提醒字段。

在后台与桌面步骤的空闲帧预先建立真实主页并读取课程缓存。完成页进入主页时，同一棵带状态的组件树在一帧内移动到目标路由，不再创建一次完整主页。磁盘读取并行进行，不作为开始动画的前置等待。主页卡片跟随已使用曲线的同一段展开进度，避免重复套用加速曲线；后台刷新仍等引导完成后才运行。

页面展开 480ms、返回 360ms，引导到主页 560ms。每个来源控件和路由拥有独立状态；接续当前显示位置与速度的阻尼曲线可在中途返回、再次展开时平滑转向。结束位置及速度作校正，保持窗口圆角与背景下沉同步。展开期间可响应目标页已显示的按钮，窗口外的其他控件也可开始独立动画。相同来源的重复打开被去重，旧动画的恢复回调不会覆盖新一轮状态；被新页面覆盖的外部链接展开会取消打开并清除临时页面。首次进入主页的引导提交仍保持完整交接后再保存完成状态。

自动验证覆盖：旧提醒迁移与幂等、保留现代通知和闹钟、系统设置兜底、可跳过的权限引导、协议与账号返回、圆环图案透明区域、慢磁盘下完成引导、真实主页状态复用、同一动画时钟交接、速度接续、并行动画、展开中返回及外部链接取消。自动测试不能代替不同手机上的帧耗时实测，不宣称测得具体帧率提升。
