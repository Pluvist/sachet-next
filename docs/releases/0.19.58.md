# Sachet Next 0.19.58 · 首个正式版

由 **Pluvist** 修改与维护，基于开源项目 Sachet 二次开发。

## 本次重点

- **UI 完全切换至 Miuix 风格**：主页、课程表、个人中心、设置及教务查询页面统一使用 Miuix 风格的标题、圆角卡片、图标、输入框、选择器和弹出菜单。
- **适配平板布局**：横屏采用顶部居中的透明导航与明暗渐变遮罩；课程表每屏并排显示两整周，每周完整七天，支持连续翻周。转回竖屏恢复单周视图。
- **优化切换流畅度**：在空闲帧预先准备另一页面，复用固定玻璃背景，将背景采样延后到动画结束，避免重复启动滑块动画。

## 同时包含

- 自动识别教学楼作息，保留普通与错峰两条时间轴及课程描边。
- 主页显示当前/下一课程、地点与倒计时；后台更新课表并保留本地缓存。
- Android 今日课程桌面小组件，默认 2×2，支持明暗模式。
- 彩色流光引导、登录与完成页面，以及从入口扩展至全屏的转场。

## 安装包选择

| 安装包 | 适用设备 |
| --- | --- |
| `arm64-v8a` | 大多数现代安卓手机和平板 |
| `armeabi-v7a` | 32 位 ARM 安卓设备 |
| `x86_64` | 64 位 x86 安卓设备或兼容模拟器 |
