# Xachet 0.19.78

- 应用和项目更名为 Xachet。
- Kotlin / Jetpack Compose 原生重写，采用液态玻璃界面与可打断动画。
- 修复教务查询及会话恢复，新增培养方案、教材关键词搜索。
- 优化课表、局部刷新和课程状态栏交互。

要求 Android 13+，提供 ARM64、ARM v7a、x86_64 安装包，沿用原正式版包名与签名。
