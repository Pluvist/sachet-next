# Sachet Next 0.19.74

本次正式版汇总了 0.19.59 之后的界面、引导、动画与桌面小组件改进，保留 Miuix 风格、平板横屏双周布局、教学楼错峰作息、课表缓存和课程实时活动。

## 主要更新

- **两种桌面小组件：** 保留 2×2 今日课程，新增四列两行的 4×2 课程概览。左侧显示当前课程状态，分割线右侧显示下一节课程、时间和地点。两种组件共享主页数据，增加随明暗模式切换的静态彩色流光与细亮边，略微降低默认高度。
- **新版启动引导：** 欢迎 → 协议 → 账号 → 后台与桌面 → 完成。增加后台运行、自启动设置入口和桌面组件添加引导，允许稍后处理；已有用户可从设置重新打开“后台与桌面”。完成图案改为空心圆中的对号。
- **过渡与预加载：** 进入主页前预先建立真实主页并读取缓存，交接时保留页面状态；控件从自身边缘展开，保留圆角和背景变暗下沉效果，速度连续，支持中途返回与独立动画并行。
- **竖屏双月课表：** 每屏完整显示上下两个月，通过上下滑动翻页，支持跨年。移除右上角切月按钮与切月箭头，保留“回到本月”；周视图与月视图独立保留位置，旋转屏幕后正确映射月份。学期最后一页补齐下一个月，超出学期部分不绘制课程。密集课程以可点击的颜色标记显示，翻月结束后恢复悬浮胶囊。
- **统一顶栏与加载：** 标题栏使用黑／白渐变遮罩，顶部不透明、向下渐隐，随明暗模式切换；修复成绩查询加载指示器被横向拉伸，改为居中圆环。
- **移除旧提醒：** 完整删除实验性功能及其上课前通知设置、调度与插件，升级时清理旧计划提醒和通知渠道。独立的课程实时活动、桌面小组件与自动更新课表功能继续保留。

## 下载与升级

- **arm64-v8a：** 多数现代 Android 手机，包括小米 17。
- **armeabi-v7a：** 32 位 ARM Android 设备。
- **x86_64：** 64 位 x86 Android 设备及兼容模拟器。

包名 **`com.pluvist.sachet.next`**，版本号 **0.19.74**，内部版本号 **42**。本次将正式版本号由 0.19.60 更正为 0.19.74，功能内容不变。沿用 0.19.59 的专用发布签名，可覆盖升级并保留应用数据；原 0.19.60 与同签名测试版也可直接升级。0.19.58 及更早版本包名不同，仍需在新版登录并同步课表。校验文件为 `SHA256SUMS.txt`，公开签名指纹见 `SIGNING-CERTIFICATE.txt`。

## 验证与说明

静态检查通过，188 项 Flutter 测试与 32 项 Android 原生单元测试通过，1 项真实账号联网测试跳过。分别构建三个架构的 release/AOT 安装包，并核对包名、版本与发布签名。测试版本已在小米 17 覆盖安装。后台运行、通知提升显示与桌面组件尺寸仍受系统及启动器设置影响，不宣称量化帧率提升。
