# Sachet Next

基于 [Sachet](https://github.com/wyvern1723/sachet) 二次开发的湘潭大学教务应用，由 **Pluvist** 修改与维护。感谢上游作者 **wyvern1723** 的开发与开源贡献。

本项目是独立修改版本。上游提供的教务系统接入、课程表、成绩与空闲教室查询等功能构成了本项目的基础。应用目前主要针对 Android 开发和验证。

## 相比上游的主要变化

| 部分 | Sachet Next 的修改 |
| --- | --- |
| 教学楼作息 | 根据地点自动识别逸夫楼、信息科技大楼，白天第 1–8 节采用比普通教学楼晚 10 分钟的作息；第 9–11 节时间一致。支持按课程手动纠正。 |
| 周课表 | 始终显示左侧普通、右侧错峰两条时间轴；课程卡片按实际时间定位，错峰卡片使用与右侧时间轴一致的主题色描边。午休、晚休缩短显示长度，保留名称。普通课程开始线与双节课结束分割线更清楚。 |
| 课程时间一致性 | 课程详情、主页状态、桌面组件、日历导出与新生成的课程提醒共用作息规则。课程卡片另有少量视觉下移，不参与真实时间、提醒或倒计时计算。 |
| 主页课程状态 | 顶部采用左大右小的三卡布局：左侧展示当前课程、地点、时间与倒计时，右上独立展示下一节的课程、时间及地点，右下进入空闲教室；左卡不可点击，无课及全部结束时显示对应提示。窄屏或大字号改为纵向排列。 |
| 主页入口 | 馆藏检索、大物实验、校园网认证进入上方九项功能卡片区；校历、新闻、邮箱进入下方校园服务列表。 |
| 页面与导航 | 参照 Miuix 与 HyperOS 参考图，以统一 Flutter 组件重写各类页面的大标题、圆角分组、彩色图标、输入框、弹窗、选择器和表格；主页卡片两侧统一对齐，设置支持搜索。悬浮胶囊仅保留左侧主页、右侧课程表；横屏使用顶部居中透明导航及渐变遮罩，周课表按两整周并排一屏查看，保留两侧时间轴；当前课程状态卡仅展示，不响应点击。个人页面改由主页右上角按钮打开。账号引导采用 HyperCeiler 布局及原彩色流光着色器转写，流程为欢迎箭头、协议与声明、登录账号、完成四步；协议需勾选同意，使用协议与隐私说明可离线阅读，账号页与协议页共用居中图标、大标题、圆角内容区及底部按钮排版，替换旧登录界面，保留密码、网页登录及 Cookie 登录方式；欢迎标题加粗且留白，完成页也保留流光；入口从箭头或卡片位置扩展至全屏，引导后默认进入主页并播放一次组件飞入，同时后台更新课表。主题默认为蓝色，周视图右上选周按钮已移除。底部渐变遮罩随亮暗模式切换，胶囊采用局部模糊、高光边缘和滑动选中层的玻璃外观，图标和文字布局保持固定宽度。取消系统壁纸动态取色，保留手动主题色。 |
| Android 课程实时活动 | 与主页共用课程数据：上课显示下课倒计时，课前/课间显示下一堂课的时间和地点，当天全部结束显示可清除的“课程已完成”提示；无课日不创建通知。支持系统实时活动的平台会请求提升显示，否则使用持续课程通知。 |
| Android 桌面组件 | 新增“今日课程”组件，默认 2×2；显示日期、周次、课程、时间、地点、状态和剩余课程数量，共享主页的课程匹配逻辑。支持尺寸调整和亮暗模式；紧凑布局四周留白 20dp，大尺寸布局 40dp。 |
| 页面性能 | 在空闲帧预先准备另一标签页，保留页面与周课表状态、按需创建周页面、复用课程缓存；玻璃背景采样合并并延后至动画结束，固定背景跨切换复用，减少切换和普通单指触摸造成的重建；双指缩放、翻周和返回交互继续保留。页面过渡统一为 iOS 风格 |
| 自动更新课表 | 冷启动及从后台恢复时先显示本地缓存，再尝试更新当前学期；未登录、断网、超时或响应异常时保留缓存。相同课表不重复写入，更新保留配色、作息修正和同学期手工日期；已开启的课程提醒随更新重新安排。 |

作息依据为学校提供的《错峰上课试行时间表》。未识别的楼名默认采用普通作息；地点缩写或教学安排不符时，可在课程详情中手动选择作息。

## 保留的上游功能

课程表导入与查看、空闲教室查询、培养方案、教材预订、考试时间、成绩查询、绩点排名、成绩单、校园常用链接及日历导出等教务功能仍以 Sachet 的实现为基础。实际可用性取决于学校教务系统与账号状态。

## Android 桌面组件

在个人页面选择桌面课程小组件，或通过桌面的小组件列表添加 **Sachet Next · 今日课程**。组件使用应用中选中的课表，无需单独导入。

默认新组件为 2×2，已有组件可手动调整大小。上课时按分钟显示倒计时，并在课程边界和日期变化时刷新；系统省电策略及闹钟权限可能影响刷新时机，点击状态图标可手动刷新。点击卡片打开应用。

界面改造的页面范围、设计参数和验证方式见 [Miuix 界面说明](docs/miuix-redesign.md)。

## Android 课程实时活动

在 **设置 → 课程实时活动** 开关中管理。完成账号引导并有课表后启用；首次遇到有课日会请求通知权限。无课当天不显示，课程已全部结束时显示普通、可清除的完成通知。课程和地点使用主页同一份解析结果，包含教学楼错峰与手动纠正；两个小节之间按课间状态显示下一节。

上课时的缩略内容隐藏课程名与地点，仅显示持续更新的纯数字倒计时（如 `42:18`），不带“下课倒计时”等标签；展开后保留课程、地点及下一节详情。课前/课间的收起通知显示下一堂课时间和完整地点，展开可查看科目与详细信息。支持的平台会申请 Android 实时活动提升显示；状态栏短文字受系统长度限制，课前使用时间与教学楼缩写，完整地点保留在通知中。外观、是否进入状态栏胶囊/锁屏活动区域由 Android 版本、厂商和系统设置决定，不使用厂商私有接口；不支持时保留持续课程通知。参考 [Android Live Updates 文档](https://developer.android.com/develop/ui/views/notifications/live-update)。

原生层持久化整学期时间戳，在课程边界、跨日、重启和修改系统时间后更新，不要求应用一直在前台，也不要求添加桌面小组件。可在设置里允许通知、系统实时活动和准时更新权限；省电限制或未允许准时更新可能使状态切换延迟。上课期间使用前台倒计时服务保持通知标题为实时数字，课间或结束后停止；亮屏时每秒刷新数字标题，熄屏时暂停标题刷新，系统计时器继续驱动缩略计时。不会按秒设置闹钟，也不持有唤醒锁；系统限制后台服务启动时保留原生计时器兜底。通知的“今天不再显示”或系统清除操作会暂停当天活动，下一次有课日恢复。

本功能当前为开发版本，自动测试与构建结果不能代替不同厂商系统上的提升显示验证；下载区仍指向已发布的 0.19.58。

## 构建与验证

开发环境：Flutter **3.24.5** / Dart **3.5.4**、JDK **17**、Android SDK **35**。详细操作见 [README_DEV.md](README_DEV.md)。

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release --target-platform android-arm64
```

保留上游内部包标识与本地数据结构；测试构建可设置 `SACHET_LOCAL_TEST=1`，使用 `io.github.wyvern1723.sachet.localtest`，与上游应用分开安装。发布构建应使用维护者自己的签名；没有签名配置时构建脚本使用开发签名。不同签名的安装包不能直接相互覆盖。

已进行自动测试、静态分析和 Android ARM64 release 构建，并在小米 17 上验证安装和主要显示效果。需要真实账号的联网测试默认跳过；未提供量化帧率对比，也不保证学校接口变更后的持续可用性。仓库保留其他平台的工程文件，新增 Android 小组件仅适用于 Android。

仓库提供手动触发的 GitHub Actions 构建与 PR 检查；生成的 APK 是测试构建。不会自动发布正式版本，也不依赖上游的签名密钥。
