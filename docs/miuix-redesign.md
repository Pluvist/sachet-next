# Miuix 界面改造

本改造参考 Miuix 的 TopAppBar、Card、BasicComponent、NavigationBar、SmallTitle 等设计，以及用户提供的 HyperOS 文件管理、设置与课表截图。实现保留 Flutter 3.24.5 / Dart 3.5.4 环境，使用项目内统一组件；未引入要求 Dart 3.12.2 的 flutter_miuix。

参考：
- https://github.com/compose-miuix-ui/miuix
- https://compose-miuix-ui.github.io/miuix/zh_CN/components/
- https://github.com/ChuxinNeko/flutter_miuix

## 设计

- 暗色背景为黑色、卡片 #222222，浅色背景 #f5f5f5、白色卡片；动态取色与用户主题色保留。
- 大标题采用常规字重，主页标题 34，展开区 144；主页及查询页面的 Sliver 标题支持随滚动收起。课表、网页登录与 PDF 使用紧凑栏。
- 统一连续圆角面板、轻量按压反馈、彩色图标底座、弱化说明文字与箭头。
- 主页九项服务采用横向卡片；常规宽度两列，窄屏/大字体一列。课程状态与空闲教室保持同色、同宽及默认高度。
- 悬浮胶囊保留主页/课表两项、个人入口仍在主页右上角；图标与文字常驻，宽度固定，只对选中背景做动画，避免切换截断。图标由项目内路径绘制，底部渐变及亮暗色边框保留。
- 设置加入搜索，可直接打开匹配的设置页面并正常返回；当前设计风格固定为 Miuix，移除旧的 Material 2/3 选择预览，保留亮暗模式与取色设置。

## 页面覆盖

| 类别 | 使用的统一界面 |
| --- | --- |
| 主页、个人、关于 | 大标题、状态卡片、功能卡片、账号分组、来源与许可入口 |
| 周/月/学期课表、课程详情、课表配置 | 紧凑工具栏、主题刻度、弹窗/底部抽屉与配置分组；保留用户课程卡片尺寸和描边 |
| 设置、主题、外观、高级、实验、开发者、配色、数据列表与数据查看 | 大标题/分组行、图标底座、搜索、表单与菜单/弹窗 |
| 空闲教室及筛选/查询/今日明日、培养方案及旧缓存、教材的各视图、成绩、绩点、考试时间、成绩单 | 可滚动标题、面板与数据表主题、筛选框、提示与反馈组件 |
| 登录、手动网页登录、PDF、首次使用引导 | 统一标题、输入框、提示面板、入口组和按钮；网页及 PDF 的内容沿用原数据 |

展示通过 `miuix_components.dart`、`miuix_settings_list.dart` 和统一 ThemeData 落地；各页面保留其业务方法和导航回调。课程卡片本体保留独立外观设置，避免覆盖用户圆角、边距及错峰描边。

## 2026-10-13 界面修正（next.3）

- 主页课程状态、空闲教室、功能网格和外部网站卡片共用左右边界；最后一项功能卡片占满整行。
- 大标题为底部日期标签保留独立空间，避免空闲教室标题与日期栏重叠。
- 移除动态取色依赖和入口，不再读取系统壁纸颜色。保留手动主题颜色和明暗模式设置，新安装默认蓝色强调色。
- 成绩查询、绩点排名、成绩单和考试反馈使用 `MiuixSelect` / `MiuixButton`，取消浮动边框标签与 Material 填充按钮外观。
- 周/月选择和课表操作菜单使用 `MiuixPopup`；周次文字使用自适应缩放，两位数不会截断。工具栏图标改为原创圆端描边图标。
- 浮动底栏增加局部背景模糊、玻璃高光边缘和滑动选中层，保留导航、语义、安全区域和底部渐变。模糊区域固定，仅移动选中层。
- 视觉与交互参考 [NexioSchedule](https://github.com/HaoZai000/NexioSchedule)。该项目采用 Compose，本次为原创 Flutter 实现，未复制其 AGPL 项目代码。当前玻璃实现使用 Flutter 背景模糊与高光，不包含其原生运行时 shader 的真实边缘折射。
- 新增标题/标签分离、窄屏双位周次、菜单切换和选择/重试回调的亮暗模式及两倍字号验证。


## 源码移植（next.4）

底栏和右上菜单现改为从 NexioSchedule 固定版本转写源码，而非 next.3 的独立外观实现。底栏两项宽42%、高56dp，滑块48dp、内边距4dp、24dp图标和11sp标签；保留按下、拖动、吸附与弹簧动画。菜单由42dp圆按钮原位变成200dp面板，圆角25dp，保留原有课表操作、外部点击/返回关闭和拖动选择。

Kyant 的 SDF、法向、边缘折射及七点色散公式已转写为 Flutter GLSL 并打包为着色器。Flutter 页面快照仅存于内存，供材质采样，页面/滚动结束时更新。原生 Compose 层捕获、滑块内图标的二次折射、精确高光与预测返回进度仍有平台差异，不宣称像素完全相同。

本组合版本采用AGPL-3.0；原Sachet MIT声明、Kyant Apache-2.0以及字体OFL分别保留并在应用许可列表中展示。原始参考文件、固定提交、许可与变更说明见 `third_party/nexio/`。


## 账号引导与拖动优化（next.5）

移除原来的多页引导，采用 HyperCeiler 引导布局转写，保留账号登录及稍后登录。取消登录不标记完成；成功登录或明确跳过后沿用持久化的引导完成状态。原系统活动转场未引入Flutter，彩色流光使用原着色器公式转写。原始来源与版权在third_party/hyperceiler/中保存。

移除周视图右上角的选周控件，保留左右翻页、滑动翻页及回到本周。首次升级本版本将已有主题迁移为蓝色一次，不改账号或课表；手动主题选择继续可用。

底栏拖动改为直接按位移更新位置，松手才启动吸附弹簧。固定背景与标签使用独立重绘边界并复用实例，滑块移除重复模糊通道。检查一帧跟手位移、固定层未重建、单次提交和取消手势回归。未宣称未经真机测量的FPS提升。


### 三步引导与原彩色流光

引导调整为彩色流光与箭头欢迎页 → 登录账号页 → 完成页。登录页可明确选择稍后登录；成功或跳过都先进入完成页，只有点击完成页按钮才持久化引导完成状态。取消登录仍返回欢迎页。

欢迎页直接转写HyperCeiler glow.glsl全套公式及GlowPainter默认参数，包含噪声、色彩插值、条纹、开场光圈和色散颜色动画，变更仅限Flutter着色器入口和uniform适配。流光仅在欢迎页绘制，进入下一页后停止帧绘制；减少动画设置使用固定时间帧。欢迎页不显示App图标，完成页使用原创黑白圆角对勾。原MIUI系统活动转场与图形后端仍有差异。

欢迎页按最终设计移除App图标，保留流光、应用文字和箭头位置；完成页仍显示黑白圆角对勾。


## 从入口扩展与引导完成（next.6）

欢迎标题使用700字重，并通过上下6dp留白及1.25行高避免字形上缘裁切。完成页与欢迎页使用同一个原彩色流光组件。

参考HyperCeiler StartupFragment的makeScaleUpAnim来源矩形，在Flutter中从实际箭头或卡片矩形缩放、扩展圆角到全屏；前进550ms easeOutCubic，返回350ms，系统减少动画时直接切换。内部功能入口打开现有页面；外部链接先扩展背景再沿用原浏览器打开方式，长按复制不变。

引导完成持久化主页为启动页，主页标题、个人入口、状态卡、空闲教室、九个功能卡和校园服务播放一次1100ms错开非线性位移、缩放与淡入，后续页面切换不重复。课表后台更新在引导完成后触发，复用现有并发去重、缓存保护与账号校验；引导期间登录不提前触发自动刷新。


## 横屏导航与两日课表（next.8）

当前课程状态卡仅展示信息，不响应点击。横屏及宽屏移除侧边导航，改为顶部居中的透明玻璃文字标签，顶端黑/白到透明渐变随主题切换；页面预留72dp，避免与原有控件遮挡。竖屏手机继续使用原悬浮底栏。

横屏周课表每屏两天，支持手势和前后按钮切换：周一/二、周三/四、周五/六、周六/日，最后一组保证周日可见且仍为两列。普通与错峰时间轴两侧保留；周次按钮、双指缩放、课程详情和竖屏七天视图继续可用。


## 横屏跨周滑动修复（next.9）

将横屏原来的“周分页内嵌日期分页”改成单一连续分页：每周四个两日分组，到周日继续左滑进入下周，周一继续右滑返回上周。顶部周次与实际课程一起更新，上一周、下一周、回到本周按逻辑周次定位并保留当前日期分组；旋转不改变当前周次。

横屏顶栏从56dp改为44dp，宽度比例从42%改为30%（限制200–320dp），文字改为14sp，顶部预留从72dp缩至60dp。竖屏底栏尺寸不变。


## 横屏两周同屏（next.10）

按修正后的需求，横屏从两天改成两整周并排：每周完整七天，各自显示周次、日期、普通与错峰时间轴。单一横向分页共10组（第1/2周至第19/20周），滑动或前两周/后两周按钮连续翻页；回到本周定位到包含本周的一组。旋转为竖屏恢复单周七天，缩小后的顶栏保持。
